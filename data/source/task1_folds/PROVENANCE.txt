IDENTITY THRESHOLD.
`Cluster` comes from CD-HIT, via the upstream parse.cluster.py ("Parse a CD-HIT .clstr
file into a hash -> cluster_id CSV") and assign.cluster.py, which joins
hash2cluster.csv onto the master by md5 of the antigen sequence. The CD-HIT
command itself is in no script -- it was run interactively -- but the cluster
file it produced, out.clstr beside those scripts upstream, bounds the threshold
exactly: 1,149 clusters over 1,660 sequences, 511 non-representative members. The MINIMUM
within-cluster identity to the representative is 90.04%, with 31 members in the
90-91% band and none below. That is `cd-hit -c 0.9`. So "antigens were clustered
at 90% sequence identity" is correct as written and does not need confirming.
